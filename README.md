# Генератор карточек кейсов Calltouch

Локальное приложение на HTML, CSS и чистом JavaScript. Сервер и сборка не нужны.

## Запуск

Можно открыть `index.html` двойным кликом. Для наиболее стабильной работы экспорта и пользовательских фоновых изображений лучше открыть папку через Live Server.

## Шрифты

Положите локальные файлы в папку `fonts`:

- `fonts/DelaGothicOne-Regular.ttf`
- `fonts/museosanscyrl-500.woff2`

Шрифты подключены через `@font-face`. Если Dela Gothic One отсутствует, браузер временно использует `Arial Black`.

## Тёмные фоны

Папка `backgrounds` уже содержит шесть тёмных изображений:

- `prez-bg-1.webp`
- `prez-bg-2.webp`
- `prez-bg-3.webp`
- `prez-bg-4.webp`
- `prez-bg-5.webp`
- `prez-bg-6.webp`

## Светлые фоны

Добавьте свои светлые PNG-изображения в папку `backgrounds-light` с теми же именами:

- `prez-bg-1.png`
- `prez-bg-2.png`
- `prez-bg-3.png`
- `prez-bg-4.png`
- `prez-bg-5.png`
- `prez-bg-6.png`

Пока светлые файлы отсутствуют, белая тема использует чистый белый фон.

## Что добавлено в этой версии

- белая тема приложения и слайда;
- светлая папка фонов с белым резервным фоном;
- опциональная коррекция фона на 30%: затемнение в тёмной теме и высветление в светлой;
- возможность оставить один, два или три показателя;
- ручные переносы строк и редактирование текста прямо на слайде для точного контроля вёрстки;
- подписи результатов без принудительного верхнего регистра;
- белые полупрозрачные плашки результатов с прозрачностью 10%;
- экспорт только слайда в JPG 3840×2160 px для более резкого результата при меньшем весе файла.
